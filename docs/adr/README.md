# SDK architecture decisions

Existing rationale and design constraints live in the [architecture map](../architecture_analysis.md),
[conventions](../engineering/conventions.md) and [resource policy](../engineering/resource-policy.md).
This folder is for new consequential decisions that need a separate record, not an assertion that no SDK decisions exist.

Prefer existing project conventions and link canonical contracts rather than copying them. Common's `domain-modeling`
and its optional `ADR-FORMAT.md` can help when needed; no new record is required for every task.
Behavioral contracts belong with their existing owner or a scoped [specification](../specs/README.md).
Shared decision guidance and blank forms remain in installed skills.
